## 📌 What is a Trojan Horse?
A **Trojan** (named after the ancient Greek myth) is a type of malware that misleads users by disguising itself as legitimate, harmless, or useful software. Unlike viruses and worms, Trojans **do not self-replicate** or infect other files on their own. They rely entirely on tricking you into running them.

---

## ⚙️ How a Trojan Works
1. **The Deception:** The attacker hides malicious code inside a desirable file (e.g., a cracked game, a free PDF converter, or a fake software update).
2. **The Delivery:** The user downloads and runs the file, believing it is safe.
3. **The Trap:** While the legitimate-looking software opens or installs, the hidden malicious payload runs quietly in the background.

---

## 🎭 Common Types of Trojans
Because they are great at sneaking past initial user defenses, attackers use them for different goals:

* **Remote Access Trojan (RAT):** Gives the attacker full, invisible remote control over your desktop, webcam, and files.
* **Downloader Trojan:** A small piece of code that sneaks onto your machine just to download and install heavier malware (like Ransomware).
* **Rootkit Trojan:** Hides deep inside the operating system core to conceal its presence from antivirus scanners.
