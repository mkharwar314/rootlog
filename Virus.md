## What is a Computer Virus?
A **virus** is a type of malware that attaches itself to a legitimate program or file. It cannot run or spread on its own—it relies completely on **human action** to execute and infect a system (like double-clicking an downloaded `.exe` file or opening a macro-enabled Excel document).

---

## How a Virus Spreads & Works
1. **Infection:** The virus injects its malicious code into an existing executable file on the system.
2. **Dormancy:** It remains hidden inside the legitimate host file, waiting for the user to run the program.
3. **Execution:** Once the user runs the infected application, the virus code runs first.
4. **Replication:** The virus seeks out other clean files on the hard drive or connected networks and infects them too.

---

## Common Signs of an Infection
* System slowdowns or random crashes (BSOD).
* Missing, corrupted, or altered files.
* Apps opening or running on their own.
* Unfamiliar software appearing without authorization.
