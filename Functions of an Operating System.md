> An operating system manages hardware resources and provides services required to run applications.

## 1. Introduction

An operating system performs several functions to ensure that a computer works efficiently.

Its main responsibility is to manage system resources and provide a convenient environment for users and applications.

## 2. Major Functions

### 2.1 Process Management

A process is a program that is currently executing.

The OS:

- Creates and terminates processes.
- Schedules processes for CPU execution.
- Allocates CPU time.
- Manages process synchronization.

**Example:** Running Chrome and PowerShell simultaneously.

### 2.2 Memory Management

Memory management controls the allocation and usage of RAM.

The OS:

- Allocates memory to processes.
- Tracks memory usage.
- Releases unused memory.
- Manages virtual memory.
- Protects process memory spaces.

**Example:** Allocating RAM to a running application.

### 2.3 File Management

The OS manages files and directories stored on storage devices.

The OS:

- Creates and deletes files.
- Organizes directories.
- Reads and writes data.
- Manages file permissions.
- Tracks storage usage.

**Example:** Creating a folder and saving a document.

### 2.4 Device Management

The OS manages hardware devices connected to the computer.

The OS:

- Communicates with devices through drivers.
- Coordinates input and output operations.
- Allocates devices when required.
- Handles device errors.

**Example:** Managing a keyboard, mouse, printer, or USB drive.

### 2.5 Security and Protection

The OS protects system resources from unauthorized access.

The OS:

- Authenticates users.
- Manages access permissions.
- Protects files and processes.
- Controls user privileges.
- Supports security auditing.

**Example:** Requiring administrator privileges to install certain software.

### 2.6 User Interface Management

The OS provides an interface between the user and the computer.

Two major types:

**GUI — Graphical User Interface**

- Uses windows, icons, menus, and buttons.
- Example: Windows Desktop.

**CLI — Command-Line Interface**

- Uses text-based commands.
- Example: PowerShell and Linux Terminal.

### 2.7 Networking

The OS provides networking capabilities for communication between devices.

The OS:

- Manages network interfaces.
- Supports network protocols.
- Configures network connections.
- Handles network communication.

**Example:** Connecting a laptop to Wi-Fi.
