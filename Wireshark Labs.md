# Wireshark Labs

> Practice packet capture and filtering using traffic generated by your own device.

## Lab rules

Capture only your own traffic or traffic explicitly within your authorization. Protect capture files because they may contain sensitive information.

## Lab 1 — Capture DNS

1. Open Wireshark and select your active interface.
2. Start capture.
3. Run `nslookup example.com` or `dig example.com`.
4. Stop capture.
5. Apply display filter:

```text
dns
```

Identify the query name, record type, response, and answer.

## Lab 2 — Observe TCP

Generate a connection to a test site, then use:

```text
tcp
```

Find a SYN, SYN-ACK, and ACK if visible. Explain the three-way handshake.

## Lab 3 — Filter by host

Use your own device's IP:

```text
ip.addr == 192.168.1.10
```

Replace the example address with your own lab address.

## Lab 4 — Inspect TLS

Use:

```text
tls
```

Observe handshake metadata. Application payload is normally encrypted; do not expect to read HTTPS page content.

## Lab report

Include capture interface, time, test traffic, filters, observations, and limitations. Do not include unrelated personal traffic.
