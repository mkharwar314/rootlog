> The operating system is the foundation that allows users and applications to interact with computer hardware.

## 1. What is an Operating System?

An Operating System (OS) is system software that manages computer hardware and software resources and provides an environment for applications to run.

It acts as an interface between the user, applications, and computer hardware.

**Examples:**

- Microsoft Windows
- Linux
- macOS
- Android
- iOS

## 2. Why Do We Need an Operating System?

Without an operating system, using a computer would be extremely difficult.

An OS helps us to:

- Run applications.
- Manage files and folders.
- Control hardware devices.
- Manage memory and processes.
- Connect to networks.
- Protect system resources.
- Interact with the computer.

## 3. How Does an Operating System Work?

The operating system acts as an intermediary between applications and hardware.

### Basic Architecture

```
+---------------------------+
|           User            |
+---------------------------+
             |
             v
+---------------------------+
|       Applications        |
+---------------------------+
             |
             v
+---------------------------+
|      Operating System     |
+---------------------------+
             |
             v
+---------------------------+
|          Kernel           |
+---------------------------+
             |
             v
+---------------------------+
|         Hardware          |
+---------------------------+
```

**Important:** The kernel is the core component of an operating system. It manages essential resources such as CPU, memory, and devices.

## 5. Operating System in Cybersecurity

Understanding operating systems is essential for cybersecurity professionals.

Security professionals study operating systems to:

- Understand user accounts and permissions.
- Analyze running processes.
- Investigate system logs.
- Identify suspicious activities.
- Understand file systems.
- Perform system hardening.
- Investigate malware behavior.

## 6. Practical Observation — Windows

Try these commands in Windows CMD or PowerShell.

**Check operating system information:**

```
systeminfo
```

**Display the Windows version:**

```
winver
```

**Display the current username:**

```
whoami
```

**Display the computer name:**

```
hostname
```
