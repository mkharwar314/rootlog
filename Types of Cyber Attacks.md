> Understanding common techniques used to compromise digital systems.

## 1. What is a Cyber Attack?

A cyber attack is an attempt to gain unauthorized access to systems, networks, or data, or to disrupt their normal operation.

## 2. Common Types of Cyber Attacks

### 1. Phishing Attack

An attacker uses fake emails, messages, or websites to trick users into revealing sensitive information.

Example: A fake banking email asking for login credentials.

### 2. Malware Attack

An attacker uses malicious software to damage, disrupt, or gain unauthorized access to systems.

Types:

- Virus
- Worm
- Trojan
- Ransomware
- Spyware

### 3. Brute Force Attack

An attacker systematically tries different password combinations until the correct password is found.

Example: Repeatedly attempting different passwords against a login page.

### 4. Denial of Service (DoS)

An attack that attempts to make a service unavailable by overwhelming it with traffic or requests.

### 5. Distributed Denial of Service (DDoS)

A DoS attack launched using multiple systems or devices against a target.

### 6. SQL Injection (SQLi)

An attack in which malicious SQL input manipulates database queries through an application.

### 7. Cross-Site Scripting (XSS)

An attack in which malicious scripts are injected into web content and executed in another user's browser.

### 8. Man-in-the-Middle (MITM)

An attack in which an attacker secretly intercepts or potentially modifies communication between two parties.

## 3. Comparison Table

|Attack|Main Target|
|---|---|
|Phishing|Human users|
|Malware|Systems and devices|
|Brute Force|Authentication|
|DoS|Service availability|
|DDoS|Service availability|
